# Konfigurasi Claude Code pribadi

Isi: subagent `quick-task` (Haiku, ringan) dan `deep-task` (Opus, sulit), aturan routing di `CLAUDE.md`, dan model `opusplan`.

## Pasang di perangkat baru (Windows)
1. Clone repo ini.
2. Klik kanan `install.ps1` > Run with PowerShell (atau jalankan `powershell -ExecutionPolicy Bypass -File install.ps1`).
3. Tutup dan buka ulang Claude Code.

File lama dicadangkan sebagai `.bak` sebelum diubah.
